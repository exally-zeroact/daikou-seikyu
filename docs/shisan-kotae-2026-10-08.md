## 代行請求書（daikou-seikyu-test）

### 1. 自社情報の 無い 客

- 今：行が 無い ⇒ defaultIssuer()＝★ZEROact の 会社名・住所・登録番号・振込先★ が 入り、そのまま 請求書に 刷られる
- 直し：行が 無い 客は ★空の 自社情報★（様式などの 既定は そのまま・会社名／振込先／登録番号 だけ 空）。ZEROact の 字は 他の 客に 出さない
- 警告：請求の 画面の 帯（regnoWarn）に「自社情報（会社名・振込先・登録番号）を入れてください（設定 ▸ 自社情報）」。会社名が 空の 間は 請求書の ボタンを 止める（登録番号の 門と 同じ 所 updateRegnoGate）
- ZEROact（本番の 1人）は 行が 在る ので 変わらない

### 2. 入金を 取って来られない 時

- 請求書（PDF・印刷・確認・Excel の 請求書・画面）は ★止めない★
- 止めるのは：
  - 入金の 保存・取り消し（入金なしに 見えた まま 上書き しない）
  - ★前回繰越を 載せる 会社★ の 請求書（入金で 繰越を 計算する）＝その 会社 だけ
  - 入金の 数を 載せる 表（入金一覧・集計・会社別集計 の Excel／集計画面の Excel）
- 文は 平らに：「通信が 途切れて 入金の 記録を 取って来られませんでした。画面を 開き直してください。」（「読めなかった」を やめる）
- 他の 3つ（自社情報・控え・番号の 台帳）を 取って来られない 時は 今まで 通り 請求書を 止める（違う 振込先・違う 番号が 出る）。文は 同じく 平らに

### 3. 番号を 揃える

## ダイコメ（dk wt-test・nyuryoku.html）

### 4. 入力画面の 日を 日本時間に

- 今：日（HI）・その日の 範囲（hiRange）・月の 端・「走った 日へ」の 日 が 端末の 時計
- 直し：全部 日本時間（+09:00）で 切る＝給料（payroll-daily.js の JST）と 同じ。日本の 端末では 1つも 変わらない
- 試験：端末の 時間帯を 日本以外（例 America/Los_Angeles）に した 画面で、日本時間 1日 03:30 の 業務が その 日に 出る・実費が その 日に 入る
