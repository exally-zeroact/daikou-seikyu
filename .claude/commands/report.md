司さん向けの完了報告を、他チャット・記録・引き継ぎにそのまま貼れる形で出力する。

絶対要件:

- ★必ず4連バッククォート( ```` )1ブロックにまとめる★。ブロック内に3連バッククォートのコードを入れない。
- 事実ベースのみ。検証していない項目は「未検証」と明記。推測・誇張・捏造を禁止。

ブロックに含める項目(該当するものだけ):

1. 何をしたか(1-3行)
2. 変更ファイル / commit SHA / push有無(Exally本番pushは1修正→実機確認→次)
3. push前チェック結果(node --check / div開閉差=0 / data-cfemail=0)
4. 次の一手

補足指定があれば考慮: $ARGUMENTS
